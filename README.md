สร้างเว็บแผนผังอาคาร (Interactive Floor Plan) แบบ Single Page ด้วย HTML/CSS/JavaScript (Vanilla JS) โดยมีรายละเอียดดังนี้:

## 1. ขนาดหน้าจอ
- ออกแบบสำหรับจอแนวตั้ง (Portrait) อัตราส่วน 9:16
- กำหนดขนาดฐานที่ 1080px × 1920px
- ใช้ width: 100vw; height: 100vh; overflow: hidden; บน body
- ให้ผังห้อง (floor plan image/SVG) แสดงเต็มพื้นที่โดยไม่มี scrollbar
- ใช้ CSS หน่วย vw/vh หรือ clamp() เพื่อให้ข้อความ/ไอคอนสเกลตามขนาดจอโดยไม่บี้หรือล้น

## 2. จุดไอคอนบนแผนผัง (Hotspot)
- แต่ละห้อง/จุดบนแผนผังมีไอคอนตำแหน่ง (marker) วางอยู่บนพิกัด x, y ที่กำหนดเอง (เก็บเป็น array ของ object เช่น {id, name, x, y, floor, category})
- ไอคอนแต่ละจุดต้องมี "เอฟเฟกต์กระพริบแบบเรดาร์" (radar pulse animation):
  - วงกลมขยายออกจากไอคอนแล้วจางหายไปซ้ำ ๆ (คล้ายคลื่นเรดาร์/สัญญาณ GPS)
  - ใช้ CSS @keyframes scale (transform: scale) + opacity fade
  - ตัวอย่าง class: .radar-pulse { animation: pulse 2s infinite; }
  - ให้กระพริบตลอดเวลาเพื่อดึงดูดสายตาผู้ใช้ ก่อนที่จะถูกกด

## 3. การโต้ตอบเมื่อกดไอคอน
- เมื่อผู้ใช้แตะ/คลิกไอคอน ให้แสดง popup หรือ panel รายละเอียดของห้องนั้น ประกอบด้วย:
  - ชื่อสถานที่/ห้อง (แก้ไขให้ถูกต้องตามข้อมูลจริง)
  - ชั้นที่ตั้ง (floor)
  - รายชื่อห้องย่อยที่อยู่ภายใน (ถ้ามีหลายห้องในโซนเดียวกัน)
  - ข้อความ "ฉันอยู่ที่นี่" (You are here) กำกับตำแหน่งปัจจุบันบนแผนที่
- popup ควรเลื่อนเข้ามาแบบ smooth animation (slide-in / fade-in)
- มีปุ่มปิด (X) เพื่อกลับไปดูแผนผังปกติ

## 4. แถบค้นหา (Search Bar)
- เพิ่มแถบค้นหาด้านบนหรือด้านล่างของแผนผัง
- ผู้ใช้พิมพ์ชื่อห้อง แล้วระบบกรอง/แสดงรายชื่อห้องที่ตรงกัน (autocomplete)
- เมื่อเลือกห้องจากผลค้นหา ให้แผนผัง zoom/pan ไปยังตำแหน่งนั้นและเปิด popup รายละเอียดโดยอัตโนมัติ พร้อม highlight ไอคอนนั้นเป็นพิเศษ (เช่น เปลี่ยนสีหรือขยายวง radar ให้ใหญ่ขึ้นชั่วคราว)

## 5. โครงสร้างข้อมูล
- แยกข้อมูลห้อง/จุดต่าง ๆ ออกเป็น JSON object ให้แก้ไขง่ายในอนาคต เช่น:
```json
[
  { "id": "ceit-1", "name": "ห้องถ่ายภาพ (Photography Studio)", "floor": "ชั้น 1", "x": 320, "y": 610 },
  { "id": "ceit-2", "name": "ห้องวางแผนสื่อ (Media Planning Room)", "floor": "ชั้น 1", "x": 320, "y": 650 }
]
```

## 6. เทคนิคเพิ่มเติม
- โค้ดต้อง responsive และรองรับ touch event (สำหรับจอสัมผัสขนาดใหญ่)
- ใช้ transition และ animation ที่ลื่นไหล ไม่กระตุก
- คอมเมนต์โค้ดเป็นภาษาไทยเพื่อให้แก้ไขง่ายภายหลัง
